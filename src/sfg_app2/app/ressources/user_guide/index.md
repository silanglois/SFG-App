# SFG-App User Guide

This is the full, illustrated user guide for **SFG-App** — the same content
reachable inside the app from **Help → User Guide**. It walks through the whole
workflow, from raw acquisition files to publication-ready plots and fitted peak
parameters.

Use the navigation on the left. If you're new, start with
[Getting Started](00_overview.md).

## Sections

- [Getting Started](00_overview.md) — the four-tab workflow and UI patterns that apply everywhere.
- [Load & Match](01_load_match.md) — bringing raw files in and organizing them into matched sets.
- [Process & Review — Homodyne](02_process_review_homodyne.md) — the homodyne processing pipeline.
- [Process & Review — Heterodyne](03_process_review_heterodyne.md) — the phase-resolved (HD-SFG) pipeline.
- [Spectra Library](04_results.md) — comparing, restyling, annotating, and exporting processed spectra.
- [Fitting](05_fitting.md) — fitting the χ⁽²⁾ model, plus batch, sequential, and global fits.
- [Settings & Preferences](06_settings_preferences.md) — every settings dialog.
- [Reference & Tips](07_reference_tips.md) — phase display, error bars, provenance, and other cross-cutting details.
